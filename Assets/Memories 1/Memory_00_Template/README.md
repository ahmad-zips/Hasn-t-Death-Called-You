# Memory 00: Template

Copy this folder to create a new memory. Full steps are in the main README, section 6.

1. Duplicate the folder and rename it, for example `Memory_05_Pride`.
2. Rename `Editor/Memory00TemplateDefinition.cs` and the class inside, for example `Memory05PrideDefinition`.
3. Change Id (unique), Folder and Title.
4. Write your layout and steps.
5. Tools → Beyond Time → Memories → 2. Build All Memory Prefabs.

Folders with "Template" in the name are built as prefabs but are not placed in the test world.
